# Phase 16.5: Multipart Upload for Large Backups

**Status**: Implementation
**Owner**: Rust Implementation Team
**Start Date**: 2026-01-05
**Target Completion**: 2026-01-05

## Overview

This phase implements robust multipart upload protocols for large backup files across all cloud storage providers (S3, GCS, Azure). Multipart upload is essential for files larger than 100MB, providing improved reliability, parallel uploads, and resumability for network interruptions.

## Natural Language Description

### Multipart Upload Protocol

Multipart upload splits large files into smaller parts (5-16MB) that can be uploaded in parallel. All parts must be uploaded before the multipart upload is "completed", which assembles the parts into the final object.

### Key Principles

1. **Part Size Calculation**: Optimal part size (5-16MB) based on provider requirements
2. **Parallel Uploads**: Upload multiple parts concurrently (default 4 parallel)
3. **Session Management**: Initiate → Upload Parts → Complete/Abort
4. **Progress Tracking**: Per-part progress callbacks with cumulative totals
5. **Resumability**: Track uploaded parts to resume from failures
6. **Error Handling**: Retry failed parts, abort entire upload on critical failures
7. **Provider-Specific**: Respect each provider's multipart upload API

### Multipart Upload Lifecycle

```
1. INITIATE: Create multipart upload session → upload_id
2. UPLOAD PARTS: Upload parts in parallel (concurrency limited)
3. COMPLETE: Assemble parts into final object → ETag
   OR
4. ABORT: Cancel upload, clean up uploaded parts (on failure)
```

### Part Size Strategy

**AWS S3**:
- Minimum part size: 5MB
- Maximum part size: 5GB
- Recommended: 16MB (balance between throughput and retry cost)
- Maximum parts: 10,000
- Max file size: 5TB

**Google Cloud Storage**:
- Minimum part size: 5MB (for resumable uploads)
- Recommended: 16MB chunks
- No maximum parts limit
- Max file size: 5TB

**Azure Blob Storage**:
- Minimum block size: 4MB
- Maximum block size: 100MB
- Recommended: 4MB blocks
- Maximum blocks: 50,000
- Max file size: 5TB

### Thresholds

| Provider    | Multipart Threshold | Default Part Size |
|-------------|---------------------|-------------------|
| S3          | 5MB                 | 16MB              |
| GCS         | 5MB                 | 16MB              |
| Azure       | 256MB               | 4MB               |

### Concurrency Limits

Parallel uploads improve throughput but must respect:
- **Default concurrency**: 4 parallel parts
- **Maximum concurrency**: 10 parallel parts (configurable)
- **Memory constraints**: Each part buffered in memory during upload
- **Rate limiting**: Don't overwhelm network or provider API

### Progress Tracking

Progress callbacks provide real-time feedback:
- **Per-part progress**: Bytes uploaded for current part
- **Cumulative progress**: Total bytes uploaded across all parts
- **Total size**: Total file size (if known upfront)
- **Part completion**: Callback invoked after each part succeeds

### Resumability

Multipart uploads are resumable:
- **Upload session tracking**: Store upload_id and part list
- **Part verification**: Track which parts succeeded
- **Resume from interruption**: Re-upload only failed parts
- **Session cleanup**: Abort abandoned uploads after timeout

### Error Handling

**Part-Level Failures** (retryable):
- Network timeout during part upload
- HTTP 5xx response from provider
- Rate limiting (429) during part upload
- Connection reset during upload

**Upload-Level Failures** (abort):
- Authentication failure (invalid credentials)
- Bucket/container not found
- Quota exceeded (hard limit)
- Too many failed parts (>50%)

**Retry Strategy**:
- Each part upload wrapped with retry logic (from Phase 16.4)
- Failed parts retried with exponential backoff
- Abort entire upload if part retry limit exceeded
- Clean up uploaded parts on abort

### Integration with Retry Logic

Multipart uploads build on retry logic from Phase 16.4:
- **Initiate**: Wrapped with retry (UploadRetryPolicy)
- **Upload Part**: Each part wrapped with retry (UploadRetryPolicy)
- **Complete**: Wrapped with retry (UploadRetryPolicy)
- **Abort**: Best-effort (no retry, cleanup is optional)

### S3 Multipart Upload Enhancement

```rust
impl S3Adapter {
    /// Upload using multipart upload API with retry logic.
    #[cfg(feature = "cloud-s3")]
    async fn upload_multipart_inner(
        &self,
        key: &str,
        data: &[u8],
        progress: Option<UploadProgress>,
    ) -> Result<String, CloudError> {
        let s3_config = self.config.s3.as_ref().unwrap();
        let part_size = s3_config.part_size.unwrap_or(DEFAULT_PART_SIZE);
        let max_concurrent = self.config.max_concurrent_uploads;

        // Validate part size
        if part_size < MIN_PART_SIZE {
            return Err(CloudError::InvalidRequest(
                format!("Part size {} below minimum {}MB",
                        part_size, MIN_PART_SIZE / 1024 / 1024)
            ));
        }

        // Split data into parts
        let parts: Vec<&[u8]> = data.chunks(part_size).collect();
        let total_parts = parts.len();
        let total_bytes = data.len();

        // Create semaphore for concurrency limiting
        let semaphore = Arc::new(Semaphore::new(max_concurrent));
        let uploaded_parts = Arc::new(Mutex::new(Vec::new()));
        let mut uploaded_bytes = 0u64;

        // Upload parts in parallel with retry
        let mut upload_tasks = Vec::new();
        for (i, chunk) in parts.iter().enumerate() {
            let permit = semaphore.clone().acquire_owned().await.map_err(|e| {
                CloudError::Other(format!("Failed to acquire upload semaphore: {}", e))
            })?;

            let client = self.client.clone();
            let bucket = self.bucket.clone();
            let key = key.to_string();
            let upload_id = upload_id.clone();
            let chunk_data = chunk.to_vec();
            let part_number = (i + 1) as i32;
            let chunk_size = chunk_data.len();
            let progress = progress.clone();
            let uploaded_parts = uploaded_parts.clone();

            let task = tokio::spawn(async move {
                let _permit = permit; // Hold permit for duration

                // Wrap part upload with retry logic
                let part_response = with_retry(|| async {
                    client
                        .upload_part()
                        .bucket(&bucket)
                        .key(&key)
                        .upload_id(&upload_id)
                        .part_number(part_number)
                        .body(ByteStream::from(chunk_data.clone()))
                        .send()
                        .await
                        .map_err(|e| self.map_s3_error(e, &key))
                }, &RetryPolicy::upload()).await?;

                let e_tag = part_response
                    .e_tag
                    .ok_or_else(|| CloudError::Other("Missing ETag for part".into()))?;

                // Track uploaded part
                let completed_part = CompletedPart::builder()
                    .part_number(part_number)
                    .e_tag(e_tag)
                    .build();

                // Update progress callback
                if let Some(cb) = &progress {
                    let mut bytes = uploaded_parts.lock().unwrap();
                    bytes.push((part_number as usize, chunk_size));
                    let total: usize = bytes.iter().map(|(_, s)| s).sum();
                    cb(total as u64, Some(total_bytes as u64));
                }

                Ok::<CompletedPart, CloudError>(completed_part)
            });

            upload_tasks.push(task);
        }

        // Wait for all parts and collect results
        let completed_parts: Vec<CompletedPart> =
            futures::future::try_join_all(upload_tasks)
                .await
                .map_err(|e| {
                    CloudError::NetworkError(format!("Multipart upload failed: {}", e))
                })?
                .into_iter()
                .collect::<Result<Vec<_>, _>>()?;

        // Sort parts by part number
        let mut sorted_parts = completed_parts;
        sorted_parts.sort_by_key(|p| p.part_number);

        // Complete multipart upload with retry
        let complete_response = with_retry(|| async {
            self.client
                .complete_multipart_upload()
                .bucket(&self.bucket)
                .key(key)
                .upload_id(&upload_id)
                .multipart_upload(
                    CompletedMultipartUpload::builder()
                        .set_parts(Some(sorted_parts.clone()))
                        .build(),
                )
                .send()
                .await
                .map_err(|e| self.map_s3_error(e, key))
        }, &RetryPolicy::upload()).await?;

        Ok(complete_response
            .e_tag
            .ok_or_else(|| CloudError::Other("Missing ETag in response".into()))?)
    }

    /// Abort multipart upload on failure.
    #[cfg(feature = "cloud-s3")]
    async fn abort_multipart_upload(
        &self,
        key: &str,
        upload_id: &str,
    ) -> Result<(), CloudError> {
        let _ = self
            .client
            .abort_multipart_upload()
            .bucket(&self.bucket)
            .key(key)
            .upload_id(upload_id)
            .send()
            .await;

        Ok(()) // Abort is best-effort
    }
}
```

### GCS Resumable Upload Enhancement

```rust
impl GcsAdapter {
    /// Upload using resumable upload with parallel chunks.
    #[cfg(feature = "cloud-gcs")]
    async fn upload_resumable_parallel(
        &self,
        key: &str,
        data: &[u8],
        progress: Option<UploadProgress>,
    ) -> Result<String, CloudError> {
        let gcs_config = self.config.gcs.as_ref().unwrap();
        let chunk_size = gcs_config.chunk_size.unwrap_or(CHUNK_SIZE);
        let max_concurrent = self.config.max_concurrent_uploads;

        // Validate chunk size
        if chunk_size < RESUMABLE_UPLOAD_THRESHOLD {
            return Err(CloudError::InvalidRequest(
                format!("Chunk size {} below minimum {}MB",
                        chunk_size, RESUMABLE_UPLOAD_THRESHOLD / 1024 / 1024)
            ));
        }

        // Split data into chunks
        let chunks: Vec<&[u8]> = data.chunks(chunk_size).collect();
        let total_chunks = chunks.len();
        let total_bytes = data.len();

        // Create semaphore for concurrency limiting
        let semaphore = Arc::new(Semaphore::new(max_concurrent));
        let uploaded_chunks = Arc::new(Mutex::new(Vec::new()));

        // Upload chunks in parallel with retry
        let mut upload_tasks = Vec::new();
        for (i, chunk) in chunks.iter().enumerate() {
            let permit = semaphore.clone().acquire_owned().await.map_err(|e| {
                CloudError::Other(format!("Failed to acquire upload semaphore: {}", e))
            })?;

            let chunk_data = chunk.to_vec();
            let chunk_index = i;
            let chunk_start = (i * chunk_size) as u64;
            let progress = progress.clone();
            let uploaded_chunks = uploaded_chunks.clone();

            let task = tokio::spawn(async move {
                let _permit = permit; // Hold permit for duration

                // Wrap chunk upload with retry logic
                with_retry(|| async {
                    self.upload_chunk_inner(key, chunk_index, chunk_start, &chunk_data).await
                }, &RetryPolicy::upload()).await?;

                // Track uploaded chunk
                let mut uploaded = uploaded_chunks.lock().unwrap();
                uploaded.push((chunk_index, chunk_data.len()));

                // Update progress callback
                if let Some(cb) = &progress {
                    let total: usize = uploaded.iter().map(|(_, s)| s).sum();
                    cb(total as u64, Some(total_bytes as u64));
                }

                Ok::<(), CloudError>(())
            });

            upload_tasks.push(task);
        }

        // Wait for all chunks to complete
        futures::future::try_join_all(upload_tasks)
            .await
            .map_err(|e| CloudError::NetworkError(format!("Resumable upload failed: {}", e)))?
            .into_iter()
            .collect::<Result<Vec<_>, _>>()?;

        // Return generation ID
        Ok("0".to_string()) // Placeholder generation ID
    }
}
```

### Azure Block Blob Upload Enhancement

```rust
impl AzureAdapter {
    /// Upload using block blob API with retry logic.
    #[cfg(feature = "cloud-azure")]
    async fn upload_block_blob_inner(
        &self,
        key: &str,
        data: &[u8],
        progress: Option<UploadProgress>,
    ) -> Result<String, CloudError> {
        let blob_client = self.container_client.blob_client(key);
        let azure_config = self.config.azure.as_ref().unwrap();
        let block_size = azure_config.block_size.unwrap_or(DEFAULT_BLOCK_SIZE);
        let max_concurrent = self.config.max_concurrent_uploads;

        // Validate block size
        if block_size < MIN_BLOCK_SIZE {
            return Err(CloudError::InvalidRequest(
                format!("Block size {} below minimum {}MB",
                        block_size, MIN_BLOCK_SIZE / 1024 / 1024)
            ));
        }

        // Split data into blocks
        let blocks: Vec<&[u8]> = data.chunks(block_size).collect();
        let total_blocks = blocks.len();
        let total_bytes = data.len();

        // Create semaphore for concurrency limiting
        let semaphore = Arc::new(Semaphore::new(max_concurrent));
        let uploaded_blocks = Arc::new(Mutex::new(Vec::new()));

        // Upload blocks in parallel with retry
        let mut upload_tasks = Vec::new();
        for (i, chunk) in blocks.iter().enumerate() {
            let permit = semaphore.clone().acquire_owned().await.map_err(|e| {
                CloudError::Other(format!("Failed to acquire upload semaphore: {}", e))
            })?;

            let client = blob_client.clone();
            let chunk_data = chunk.to_vec();
            let block_id = Self::generate_block_id(i);
            let progress = progress.clone();
            let uploaded_blocks = uploaded_blocks.clone();

            let task = tokio::spawn(async move {
                let _permit = permit; // Hold permit for duration

                // Wrap block upload with retry logic
                with_retry(|| async {
                    client
                        .put_block()
                        .block_id(&block_id)
                        .body(chunk_data.clone())
                        .execute()
                        .await
                        .map_err(|e| self.map_azure_error(e, key))
                }, &RetryPolicy::upload()).await?;

                // Track uploaded block
                let mut uploaded = uploaded_blocks.lock().unwrap();
                uploaded.push((i, block_id.clone(), chunk_data.len()));

                // Update progress callback
                if let Some(cb) = &progress {
                    let total: usize = uploaded.iter().map(|(_, _, s)| s).sum();
                    cb(total as u64, Some(total_bytes as u64));
                }

                Ok::<(), CloudError>(())
            });

            upload_tasks.push(task);
        }

        // Wait for all blocks to complete
        futures::future::try_join_all(upload_tasks)
            .await
            .map_err(|e| CloudError::NetworkError(format!("Block blob upload failed: {}", e)))?
            .into_iter()
            .collect::<Result<Vec<_>, _>>()?;

        // Sort blocks by index
        let mut uploaded = uploaded_blocks.lock().unwrap();
        uploaded.sort_by_key(|(i, _, _)| *i);

        // Extract block IDs in order
        let block_ids: Vec<String> = uploaded.iter().map(|(_, id, _)| id.clone()).collect();

        // Commit block list with retry
        let commit_response = with_retry(|| async {
            blob_client
                .put_block_list()
                .block_list(block_ids.clone())
                .execute()
                .await
                .map_err(|e| self.map_azure_error(e, key))
        }, &RetryPolicy::upload()).await?;

        Ok(commit_response
            .e_tag
            .ok_or_else(|| CloudError::Other("Missing ETag in response".into()))?)
    }
}
```
