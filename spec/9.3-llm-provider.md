# LLM Provider Interface v1 Specification

**Version**: 1.0
**Date**: 2026-01-05
**Status**: Draft
**Phase**: 9.3 - AI Intelligence Layer

## Overview

This specification defines a provider-agnostic interface for Large Language Model (LLM) integration in NorthstarDB. The interface enables plugins to interact with multiple LLM providers (OpenAI, Anthropic, local models) through a unified API, supporting chat completions, streaming responses, and function calling with automatic schema validation.

## Design Goals

1. **Provider Agnosticism**: Single interface for OpenAI, Anthropic, and local models
2. **Function Calling**: Structured function calls with JSON schema validation
3. **Streaming Support**: Real-time streaming responses for interactive experiences
4. **Error Resilience**: Automatic retries, fallbacks, and graceful degradation
5. **Resource Management**: Rate limiting, quota enforcement, and connection pooling
6. **Type Safety**: Strong typing for requests, responses, and function schemas

```rust
pub struct OpenAIProvider {
    config: OpenAIConfig,
    client: reqwest::Client,
    rate_limiter: Arc<RateLimiter>,
}

impl OpenAIProvider {
    pub fn new(config: OpenAIConfig) -> Result<Self> {
        let client = reqwest::Client::builder()
            .timeout(config.timeout)
            .build()?;

        let rate_limiter = Arc::new(RateLimiter::new(
            config.rate_limit.requests_per_minute,
            config.rate_limit.tokens_per_minute,
        ));

        Ok(Self {
            config,
            client,
            rate_limiter,
        })
    }

    async fn make_request<T: serde::de::DeserializeOwned>(
        &self,
        endpoint: &str,
        payload: serde_json::Value,
    ) -> Result<T> {
        // Check rate limits
        self.rate_limiter.check_request()?;

        // Build request
        let url = format!("{}/{}", self.base_url(), endpoint);
        let mut request = self.client
            .post(&url)
            .header("Authorization", format!("Bearer {}", self.config.api_key))
            .json(&payload);

        if let Some(org_id) = &self.config.organization_id {
            request = request.header("OpenAI-Organization", org_id);
        }

        // Execute with retry
        let response = retry_with_backoff(&self.config.retry_config, || {
            Box::pin(async {
                request
                    .try_clone()
                    .unwrap()
                    .send()
                    .await
                    .map_err(|e| LlmError::NetworkError(e.to_string()))
            })
        }).await?;

        // Parse response
        if response.status().is_success() {
            let body = response.text().await?;
            serde_json::from_str(&body)
                .map_err(|e| LlmError::ParseError(e.to_string()))
        } else {
            let status = response.status();
            let body = response.text().await?;
            Err(parse_openai_error(status, &body))
        }
    }
}
```

## Function Schema System

### Schema Definition

```rust
pub struct FunctionSchema {
    pub name: String,
    pub description: String,
    pub parameters: ParametersSchema,
}

pub struct ParametersSchema {
    pub schema_type: String,  // "object"
    pub properties: HashMap<String, PropertySchema>,
    pub required: Vec<String>,
}

pub struct PropertySchema {
    pub schema_type: String,
    pub description: Option<String>,
    pub enum_values: Option<Vec<serde_json::Value>>,
    pub nested: Option<Box<ParametersSchema>>,
}

/// Builder for function schemas
pub struct FunctionSchemaBuilder {
    name: String,
    description: String,
    properties: HashMap<String, PropertySchema>,
    required: Vec<String>,
}

impl FunctionSchemaBuilder {
    pub fn new(name: impl Into<String>, description: impl Into<String>) -> Self {
        Self {
            name: name.into(),
            description: description.into(),
            properties: HashMap::new(),
            required: Vec::new(),
        }
    }

    pub fn add_property(
        mut self,
        name: impl Into<String>,
        schema_type: impl Into<String>,
        description: impl Into<String>,
    ) -> Self {
        let prop = PropertySchema {
            schema_type: schema_type.into(),
            description: Some(description.into()),
            enum_values: None,
            nested: None,
        };
        self.properties.insert(name.into(), prop);
        self
    }

    pub fn add_required(mut self, name: impl Into<String>) -> Self {
        self.required.push(name.into());
        self
    }

    pub fn build(self) -> FunctionSchema {
        FunctionSchema {
            name: self.name,
            description: self.description,
            parameters: ParametersSchema {
                schema_type: "object".to_string(),
                properties: self.properties,
                required: self.required,
            },
        }
    }
}
```

```rust
pub struct LlmClientFactory;

impl LlmClientFactory {
    pub fn create_openai(config: OpenAIConfig) -> Result<Arc<dyn LlmProvider>> {
        Ok(Arc::new(OpenAIProvider::new(config)?))
    }

    pub fn create_anthropic(config: AnthropicConfig) -> Result<Arc<dyn LlmProvider>> {

    }

    pub fn create_local(config: LocalModelConfig) -> Result<Arc<dyn LlmProvider>> {
        Ok(Arc::new(LocalModelProvider::new(config)?))
    }

    /// Create from environment variables
    pub fn from_env(provider: &str) -> Result<Arc<dyn LlmProvider>> {
        match provider.to_lowercase().as_str() {
            "openai" => Self::create_openai(OpenAIConfig::default()),
            "anthropic" => Self::create_anthropic(AnthropicConfig::default()),
            "local" => Self::create_local(LocalModelConfig::default()),
            _ => Err(LlmError::InvalidRequest(format!(
                "Unknown provider: {}",
                provider
            ))),
        }
    }

    /// Create with automatic fallback chain
    pub fn with_fallback(
        primary: Arc<dyn LlmProvider>,
        fallbacks: Vec<Arc<dyn LlmProvider>>,
    ) -> FallbackProvider {
        FallbackProvider::new(primary, fallbacks)
    }
}
```

## Fallback Provider

```rust
pub struct FallbackProvider {
    primary: Arc<dyn LlmProvider>,
    fallbacks: Vec<Arc<dyn LlmProvider>>,
}

impl FallbackProvider {
    pub fn new(
        primary: Arc<dyn LlmProvider>,
        fallbacks: Vec<Arc<dyn LlmProvider>>,
    ) -> Self {
        Self {
            primary,
            fallbacks,
        }
    }
}

impl LlmProvider for FallbackProvider {
    fn name(&self) -> &str {
        "fallback"
    }

    async fn chat_completion(&self, request: ChatRequest) -> Result<ChatResponse> {
        // Try primary
        match self.primary.chat_completion(request.clone()).await {
            Ok(response) => Ok(response),
            Err(e) => {
                tracing::warn!(
                    provider = %self.primary.name(),
                    error = %e,
                    "Primary provider failed, trying fallbacks"
                );

                // Try fallbacks in order
                for fallback in &self.fallbacks {
                    match fallback.chat_completion(request.clone()).await {
                        Ok(response) => {
                            tracing::info!(
                                provider = %fallback.name(),
                                "Fallback provider succeeded"
                            );
                            return Ok(response);
                        }
                        Err(e) => {
                            tracing::warn!(
                                provider = %fallback.name(),
                                error = %e,
                                "Fallback provider failed"
                            );
                            continue;
                        }
                    }
                }

                // All failed
                Err(LlmError::ProviderUnavailable(
                    "All providers failed".to_string()
                ))
            }
        }
    }

    // Similar for other methods
}
```

## Performance Requirements

### Latency Targets

- **Chat completion**: <2s (p50), <5s (p99)
- **Function call**: <3s (p50), <8s (p99)
- **Streaming first token**: <500ms (p50)
- **Health check**: <100ms

### Throughput Targets

- **OpenAI**: 3000 requests/minute, 200K tokens/minute
- **Anthropic**: 1000 requests/minute, 80K tokens/minute
- **Local**: Limited by hardware

### Resource Limits

- **Max concurrent requests**: 100 per provider
- **Connection pool size**: 10 per provider
- **Request timeout**: 60s default
- **Max retries**: 3 attempts

## Security Considerations

### API Key Management

- API keys loaded from environment only
- Never log API keys
- Support for key rotation
- Separate keys for development/production

### Input Validation

- Sanitize all user inputs before sending to LLM
- Validate function call arguments
- Limit message lengths (prevent DoS)

### Rate Limiting

- Enforce provider rate limits
- Per-provider quota tracking
- Automatic backoff on limits

### Audit Logging

- Log all LLM API calls
- Track token usage
- Monitor errors and fallbacks
- Cost tracking

## Testing Requirements

### Unit Testing

- Provider trait compliance tests
- Error handling tests
- Rate limiting tests
- Retry logic tests
- Function schema validation tests

### Integration Testing

- Real API calls (with test keys)
- Streaming response tests
- Function calling end-to-end tests
- Fallback provider tests
- Rate limit enforcement tests

### Mock Testing

- Mock HTTP responses for unit tests
- Test error scenarios (timeouts, 500 errors)
- Test retry behavior

## Future Enhancements

### Phase 9.4: Advanced Features

- **Response caching**: Cache similar requests
- **Prompt optimization**: Automatic prompt compression
