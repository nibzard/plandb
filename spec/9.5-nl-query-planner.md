# Phase 9.5: Natural Language Query Planner

## Overview

The Natural Language Query Planner enables users to query NorthstarDB using natural language instead of structured query syntax. It translates human-readable queries into optimized database operations using LLM function calling, leveraging the entity/topic cartridges for semantic understanding.

### Core Objectives

1. **Natural Language Interface**: Accept queries in plain English (or other languages)
2. **Intent Classification**: Determine query type (point lookup, range scan, aggregation, semantic search)
3. **Entity Resolution**: Link entity references in queries to cartridge data
4. **Query Planning**: Generate optimal execution plans using cartridge indices
5. **Result Ranking**: Rank and score results by relevance for semantic queries
6. **Explainability**: Provide query explanations and execution plans

### Integration Points

- **Consumes**: User natural language queries
- **Uses**: LlmProvider from Phase 9.3 for function calling
- **Uses**: EntityCartridge, TopicCartridge, RelationshipCartridge from Phase 9.4
- **Produces**: QueryPlan for execution
- **Enables**: Time-travel queries via LSN parameters

## Natural Language Description

### Query Translation Pipeline

```
User Query: "Show me all functions modified by nikos in the storage layer"
    ↓
1. Intent Classification: Semantic Search + Filter
    ↓
2. Entity Extraction: {nikos → PersonEntity, storage layer → Topic}
    ↓
3. Entity Linking: nikos → person:123, storage layer → topic:456
    ↓
4. Query Planning:
   - Scan PersonEntity "nikos" → find commits
   - Filter by Topic "storage layer"
   - Retrieve FunctionEntity from those commits
    ↓
5. Optimization: Use topic index → person index
    ↓
6. Execution: Return ranked list of functions
```

### Supported Query Patterns

1. **Point Lookup**: "Get file src/db.zig"
2. **Range Scan**: "Show all files modified between 2024-01-01 and 2024-01-31"
3. **Entity Search**: "Find all functions in the btree module"
4. **Relationship Traversal**: "What files does nikos modify?"
5. **Aggregation**: "Count all commits by nikos"
6. **Semantic Search**: "Show storage-related work"
7. **Time Travel**: "What did the database look like after commit 12345?"
8. **Complex Queries**: "Find all performance optimizations in the storage layer by nikos"

### Intent Detection Strategy

1. **Keyword Patterns**: "show", "get", "find" → lookup/search
2. **Aggregate Keywords**: "count", "sum", "average" → aggregation
3. **Temporal Keywords**: "between", "before", "after" → range/time-travel
4. **Relationship Keywords**: "modified by", "contains", "related to" → traversal
5. **Semantic Analysis**: LLM classification for ambiguous queries

```rust
pub struct EntityLinker {
    entity_cartridge: Arc<EntityCartridge>,
    topic_cartridge: Arc<TopicCartridge>,

impl EntityLinker {
    /// Link entity reference to cartridge entry
    pub async fn link(
        &self,
        text: &str,
        entity_type: EntityType,
    ) -> Result<Vec<LinkResult>> {
        // 1. Exact match lookup
        if let Some(entity) = self.exact_match(text, entity_type)? {
            return Ok(vec![LinkResult {
                entity_id: entity.id.clone(),
                confidence: 1.0,
                match_type: MatchType::Exact,
            }]);
        }

        // 2. Fuzzy match (Levenshtein distance)
        let fuzzy_matches = self.fuzzy_match(text, entity_type)?;

        // 3. Semantic match (using topic keywords)
        let semantic_matches = self.semantic_match(text, entity_type)?;

        // 4. Merge and rank results
        Ok(self.merge_and_rank(fuzzy_matches, semantic_matches))
    }

    fn exact_match(&self, text: &str, entity_type: EntityType) -> Result<Option<Entity>> {
        match entity_type {
            EntityType::Person => {
                if let Some(entity) = self.entity_cartridge.get_by_name(text) {
                    return Ok(Some(entity.clone()));
                }
            },
            EntityType::Topic => {
                if let Some(topic) = self.topic_cartridge.get_by_name(text) {
                    return Ok(Some(Entity::Topic(topic.clone())));
                }
            },
            _ => {},
        }
        Ok(None)
    }
}

pub struct LinkResult {
    pub entity_id: String,
    pub confidence: f32,
    pub match_type: MatchType,
}

pub enum MatchType {
    Exact,      // Direct name match
    Fuzzy,      // Edit distance match
    Semantic,   // Topic keyword match
    Partial,    // Partial string match
}
```

### Fuzzy Matching Algorithm

```rust
fn fuzzy_match(&self, text: &str, entity_type: EntityType) -> Result<Vec<LinkResult>> {
    let entities = match entity_type {
        EntityType::Person => self.entity_cartridge.get_all_persons()?,
        EntityType::Topic => return Ok(vec![]), // Topics use semantic match
        _ => return Ok(vec![]),
    };

    let mut results = Vec::new();

    for entity in entities {
        let distance = levenshtein_distance(text, &entity.name());
        let similarity = 1.0 - (distance as f32 / text.len().max(entity.name().len()) as f32);

        if similarity >= self.fuzzy_threshold {
            results.push(LinkResult {
                entity_id: entity.id().to_string(),
                confidence: similarity,
                match_type: MatchType::Fuzzy,
            });
        }
    }

    results.sort_by(|a, b| b.confidence.partial_cmp(&a.confidence).unwrap());
    Ok(results)
}
```

### Query Planner

```rust
pub struct QueryPlanner {
    llm: Arc<dyn LlmProvider>,
    entity_cartridge: Arc<RwLock<EntityCartridge>>,
    topic_cartridge: Arc<RwLock<TopicCartridge>>,
    relationship_cartridge: Arc<RwLock<RelationshipCartridge>>,
    entity_linker: Arc<EntityLinker>,
    config: QueryPlannerConfig,
}

pub struct QueryPlannerConfig {
    pub max_plan_complexity: usize,
    pub enable_caching: bool,
    pub default_rank_threshold: f32,
    pub max_results_no_limit: usize,
}

impl QueryPlanner {
    /// Translate natural language to query plan
    pub async fn plan(&self, nl_query: &str) -> Result<QueryPlan> {
        // 1. Classify intent
        let intent = self.classify_intent(nl_query).await?;

        // 2. Extract entities from query
        let extracted_entities = self.extract_entities(nl_query).await?;

        // 3. Link entities to cartridges
        let mut entity_links = HashMap::new();
        for entity in &extracted_entities {
            let links = self.entity_linker.link(&entity.text, entity.entity_type).await?;
            if let Some(best_link) = links.first() {
                entity_links.insert(entity.text.clone(), best_link.entity_id.clone());
            }
        }

        // 4. Generate query operations
        let operations = self.generate_operations(&intent, &entity_links).await?;

        // 5. Optimize plan
        let (operations, hint) = self.optimizer.optimize(operations, &entity_links)?;

        // 6. Estimate cost
        let cost = self.estimate_cost(&operations);

        Ok(QueryPlan {
            intent,
            operations,
            entity_links,
            estimated_cost: cost,
            execution_hint: hint,
        })
    }

    /// Explain the query plan
    pub async fn explain(&self, nl_query: &str) -> Result<Explanation> {
        let plan = self.plan(nl_query).await?;

        Ok(Explanation {
            original_query: nl_query.to_string(),
            intent: format!("{:?}", plan.intent),
            operations: plan.operations.iter()
                .map(|op| format!("{:?}", op))
                .collect(),
            entity_links: plan.entity_links,
            estimated_cost: plan.estimated_cost,
            execution_strategy: format!("{:?}", plan.execution_hint),
            optimization_notes: self.get_optimization_notes(&plan),
        })
    }

    async fn classify_intent(&self, query: &str) -> Result<QueryIntent> {
        // Use LLM function calling to classify intent
        let schema = FunctionSchemaBuilder::new("classify_query_intent")
            .description("Classify the intent of a database query")
            .parameter("intent", PropertySchema::string("Query intent type")
                .enum_values(["point_lookup", "range_scan", "semantic_search", "aggregation", "relationship_traversal", "time_travel", "complex"]))
            .parameter("aggregation_type", PropertySchema::string("Type of aggregation if applicable")
                .enum_values(["count", "sum", "average", "min", "max"])
                .optional())
            .parameter("target_entity", PropertySchema::string("Main entity type being queried")
                .enum_values(["file", "function", "person", "topic", "config"])
                .optional())
            .required(["intent"])
            .build();

        let request = ChatRequest {
            model: "gpt-4-turbo".to_string(),
            messages: vec![
                ChatMessage {
                    role: ChatRole::System,
                    content: "You are a query classifier. Analyze the user's query and determine its intent.".to_string(),
                },
                ChatMessage {
                    role: ChatRole::User,
                    content: query.to_string(),
                },
            ],
            temperature: 0.0,
            max_tokens: Some(100),
            ..Default::default()
        };

        let response = self.llm.call_function(request, &schema).await?;

        // Parse response into QueryIntent
        self.parse_intent_response(response)
    }

    async fn extract_entities(&self, query: &str) -> Result<Vec<ExtractedEntity>> {
        let schema = FunctionSchemaBuilder::new("extract_entities")
            .description("Extract entity references from a natural language query")
            .parameter("entities", PropertySchema::array("Extracted entities")
                .items(PropertySchema::object("Entity")
                    .property("text", PropertySchema::string("Entity text as it appears in query"))
                    .property("entity_type", PropertySchema::string("Type of entity")
                        .enum_values(["person", "topic", "file", "function", "config"]))
                    .property("confidence", PropertySchema::number("Confidence score 0-1"))
                    .required(["text", "entity_type", "confidence"])))
            .required(["entities"])
            .build();

        let request = ChatRequest {
            model: "gpt-4-turbo".to_string(),
            messages: vec![
                ChatMessage {
                    role: ChatRole::System,
                    content: "Extract entity references from the query. Entities include people, topics, files, functions, and configs.".to_string(),
                },
                ChatMessage {
                    role: ChatRole::User,
                    content: query.to_string(),
                },
            ],
            temperature: 0.0,
            max_tokens: Some(200),
            ..Default::default()
        };

        let response = self.llm.call_function(request, &schema).await?;
        self.parse_entity_response(response)
    }

    async fn generate_operations(
        &self,
        intent: &QueryIntent,
        entity_links: &HashMap<String, String>,
    ) -> Result<Vec<QueryOperation>> {
        match intent {
            QueryIntent::PointLookup => {
                // Generate single point lookup operation
                Ok(vec![QueryOperation::EntityLookup {
                    cartridge_type: CartridgeType::Entity,
                    lookup_type: LookupType::ById,
                    key: entity_links.values().next().unwrap().clone(),
                }])
            },
            QueryIntent::SemanticSearch => {
                // Generate entity lookup + relationship traversal
                let mut ops = vec![];

                // Look up linked entities
                for entity_id in entity_links.values() {
                    ops.push(QueryOperation::EntityLookup {
                        cartridge_type: CartridgeType::Entity,
                        lookup_type: LookupType::ById,
                        key: entity_id.clone(),
                    });
                }

                // Traverse relationships
                ops.push(QueryOperation::RelationshipTraversal {
                    from_entity: entity_links.values().next().unwrap().clone(),
                    rel_type: RelationshipType::RelatedTo,
                    direction: TraversalDirection::Both,
                    max_depth: 2,
                });

                Ok(ops)
            },
            QueryIntent::Aggregation { agg_type, field } => {
                Ok(vec![
                    QueryOperation::Aggregate {
                        agg_type: agg_type.clone(),
                        field: field.clone(),
                        group_by: None,
                    },
                ])
            },
            _ => Ok(vec![]),
        }
    }

    fn estimate_cost(&self, operations: &[QueryOperation]) -> f32 {
        operations.iter().map(|op| match op {
            QueryOperation::PointLookup { .. } => 1.0,
            QueryOperation::RangeScan { .. } => 10.0,
            QueryOperation::EntityLookup { .. } => 2.0,
            QueryOperation::RelationshipTraversal { max_depth, .. } => *max_depth as f32 * 5.0,
            QueryOperation::Filter { .. } => 3.0,
            QueryOperation::Aggregate { .. } => 5.0,
            QueryOperation::Sort { .. } => 8.0,
            QueryOperation::Limit { .. } => 0.5,
        }).sum()
    }
}

    pub operations: Vec<String>,
    pub entity_links: HashMap<String, String>,
    pub estimated_cost: f32,
    pub execution_strategy: String,
    pub optimization_notes: Vec<String>,
}
```

```rust
pub struct QueryOptimizer {
    entity_cartridge: Arc<RwLock<EntityCartridge>>,
    topic_cartridge: Arc<RwLock<TopicCartridge>>,
    relationship_cartridge: Arc<RwLock<RelationshipCartridge>>,
    query_cache: Arc<RwLock<HashMap<String, CachedPlan>>>,
}

struct CachedPlan {
    plan: QueryPlan,
    timestamp: SystemTime,
    hit_count: u32,
}

impl QueryOptimizer {
    /// Optimize query operations
    pub fn optimize(
        &self,
        operations: Vec<QueryOperation>,
        entity_links: &HashMap<String, String>,
    ) -> Result<(Vec<QueryOperation>, ExecutionHint)> {
        let mut ops = operations;

        // 1. Reorder operations (most selective first)
        ops = self.reorder_operations(ops);

        // 2. Add index hints
        let hint = self.generate_hint(&ops, entity_links);

        // 3. Push down filters
        ops = self.push_down_filters(ops);

        // 4. Merge aggregations
        ops = self.merge_aggregations(ops);

        Ok((ops, hint))
    }

    fn reorder_operations(&self, mut ops: Vec<QueryOperation>) -> Vec<QueryOperation> {
        // Sort by selectivity (point lookups first, scans last)
        ops.sort_by(|a, b| {
            let cost_a = self.operation_selectivity(a);
            let cost_b = self.operation_selectivity(b);
            cost_a.partial_cmp(&cost_b).unwrap()
        });
        ops
    }

    fn operation_selectivity(&self, op: &QueryOperation) -> f32 {
        match op {
            QueryOperation::PointLookup { .. } => 1.0,  // Most selective
            QueryOperation::EntityLookup { lookup_type, .. } => match lookup_type {
                LookupType::ById => 1.0,
                LookupType::ByName => 2.0,
                LookupType::ByType => 10.0,
                LookupType::ByCommit => 20.0,
                _ => 5.0,
            },
            QueryOperation::Filter { .. } => 5.0,
            QueryOperation::RelationshipTraversal { .. } => 15.0,
            QueryOperation::RangeScan { .. } => 50.0,  // Least selective
            _ => 10.0,
        }
    }

    fn generate_hint(
        &self,
        ops: &[QueryOperation],
        entity_links: &HashMap<String, String>,
    ) -> ExecutionHint {
        // Check if we can use indices
        for op in ops {
            if let QueryOperation::EntityLookup { lookup_type, key } = op {
                match lookup_type {
                    LookupType::ByName => {
                        return ExecutionHint::UseIndex {
                            index_name: "entity:name".to_string(),
                        };
                    },
                    LookupType::ByType => {
                        return ExecutionHint::UseIndex {
                            index_name: format!("entity:type:{}", key),
                        };
                    },
                    _ => {},
                }
            }
        }

        // Check for parallelizable operations
        if ops.len() > 2 && self.are_operations_independent(ops) {
            return ExecutionHint::Parallelize;
        }

        ExecutionHint::UseCache
    }

    fn push_down_filters(&self, ops: Vec<QueryOperation>) -> Vec<QueryOperation> {
        // Move filters as early as possible in the pipeline
        let mut filters: Vec<QueryOperation> = Vec::new();
        let mut others: Vec<QueryOperation> = Vec::new();

        for op in ops {
            if matches!(op, QueryOperation::Filter { .. }) {
                filters.push(op);
            } else {
                others.push(op);
            }
        }

        // Combine: filters first, then other operations
        let mut result = filters;
        result.extend(others);
        result
    }

    fn merge_aggregations(&self, ops: Vec<QueryOperation>) -> Vec<QueryOperation> {
        // Combine multiple aggregations into one
        let mut aggregations: Vec<QueryOperation> = Vec::new();
        let mut others: Vec<QueryOperation> = Vec::new();

        for op in ops {
            if matches!(op, QueryOperation::Aggregate { .. }) {
                aggregations.push(op);
            } else {
                others.push(op);
            }
        }

        // If multiple aggregations, merge into single multi-aggregation
        if aggregations.len() > 1 {
            // For now, keep them separate (future: combine)
        }

        let mut result = others;
        result.extend(aggregations);
        result
    }

    fn are_operations_independent(&self, ops: &[QueryOperation]) -> bool {
        // Check if operations can be parallelized
        // Simplified: operations are independent if they don't depend on each other's results
        true  // Conservative default
    }
}
```

## Result Ranking and Relevance Scoring

### Ranking Algorithm

```rust
pub struct ResultRanker {
    entity_cartridge: Arc<RwLock<EntityCartridge>>,
    topic_cartridge: Arc<RwLock<TopicCartridge>>,
}

impl ResultRanker {
    /// Rank query results by relevance
    pub fn rank(
        &self,
        results: Vec<Entity>,
        query: &QueryPlan,
    ) -> Result<Vec<RankedEntity>> {
        let mut ranked: Vec<RankedEntity> = results.into_iter().map(|entity| {
            let score = self.calculate_relevance(&entity, query);
            RankedEntity {
                entity,
                relevance_score: score,
                rank_reason: self.explain_score(&entity, query, score),
            }
        }).collect();

        ranked.sort_by(|a, b| {
            b.relevance_score.partial_cmp(&a.relevance_score).unwrap()
        });

        Ok(ranked)
    }

    fn calculate_relevance(&self, entity: &Entity, query: &QueryPlan) -> f32 {
        let mut score = 0.0;

        // 1. Exact match bonus
        if let Some(linked_id) = query.entity_links.values().next() {
            if entity.id() == linked_id {
                score += 1.0;
            }
        }

        // 2. Confidence score from extraction
        score += entity.confidence() * 0.5;

        // 3. Recency bonus (more recent commits = higher score)
        if let Some(commit_id) = entity.commit_id() {
            let recency = self.calculate_recency(commit_id);
            score += recency * 0.3;
        }

        // 4. Topic relevance
        if let QueryIntent::SemanticSearch = &query.intent {
            if let Ok(topic_relevance) = self.calculate_topic_relevance(entity, query) {
                score += topic_relevance * 0.4;
            }
        }

        score.min(1.0)
    }

    fn calculate_recency(&self, commit_id: u64) -> f32 {
        // Normalize commit ID to 0-1 range (higher = more recent)
        // Simplified: assume commit IDs are monotonically increasing
        1.0 / (1.0 + (1_000_000 - commit_id.min(1_000_000)) as f32 / 100_000.0)
    }

    fn calculate_topic_relevance(&self, entity: &Entity, query: &QueryPlan) -> Result<f32> {
        // Check if entity is related to queried topics
        Ok(0.5)  // Placeholder
    }

    fn explain_score(&self, entity: &Entity, query: &QueryPlan, score: f32) -> String {
        let mut reasons = Vec::new();

        if score > 0.8 {
            reasons.push("High confidence match");
        }

        if entity.confidence() > 0.8 {
            reasons.push("High extraction confidence");
        }

        if let Some(commit_id) = entity.commit_id() {
            if self.calculate_recency(commit_id) > 0.5 {
```

### Semantic Queries

```rust
impl QueryPlanner {
    /// Execute semantic query using cartridges
    pub async fn execute_semantic(
        &self,
        plan: &QueryPlan,
    ) -> Result<Vec<Entity>> {
        let mut results = Vec::new();

        for operation in &plan.operations {
            match operation {
                QueryOperation::EntityLookup { cartridge_type, lookup_type, key } => {
                    match cartridge_type {
                        CartridgeType::Entity => {
                            let cartridge = self.entity_cartridge.read().unwrap();
                            let entity = match lookup_type {
                                LookupType::ById => cartridge.get_by_id(key)?,
                                LookupType::ByName => cartridge.get_by_name(key)?.map(|e| e.clone()),
                                LookupType::ByType => {
                                    cartridge.get_by_type(EntityType::from_str(key))
                                        .into_iter()
                                        .next()
                                        .and_then(|id| cartridge.get_by_id(&id).ok())
                                },
                                _ => None,
                            };

                            if let Some(e) = entity {
                                results.push(e);
                            }
                        },
                        CartridgeType::Topic => {
                            let cartridge = self.topic_cartridge.read().unwrap();
                            if let Some(topic) = cartridge.get_by_name(key)? {
                                results.push(Entity::Topic(topic.clone()));
                            }
                        },
                        _ => {},
                    }
                },
                QueryOperation::RelationshipTraversal { from_entity, rel_type, direction, max_depth } => {
                    let cartridge = self.relationship_cartridge.read().unwrap();

                    match direction {
                        TraversalDirection::Outgoing => {
                            let rels = cartridge.get_from(from_entity)?;
                            for rel in rels {
                                if rel.rel_type == *rel_type {
                                    // Get related entity
                                    if let Some(entity) = self.entity_cartridge.read().unwrap()
                                        .get_by_id(&rel.to_entity)?
                                    {
                                        results.push(entity.clone());
                                    }
                                }
                            }
                        },
                        TraversalDirection::Incoming => {
                            let rels = cartridge.get_to(from_entity)?;
                            for rel in rels {
                                if rel.rel_type == *rel_type {
                                    if let Some(entity) = self.entity_cartridge.read().unwrap()
                                        .get_by_id(&rel.from_entity)?
                                    {
                                        results.push(entity.clone());
                                    }
                                }
                            }
                        },
                        TraversalDirection::Both => {
                            // Combine both directions
                            let mut outgoing = cartridge.get_from(from_entity)?;
                            let mut incoming = cartridge.get_to(from_entity)?;
                            outgoing.append(&mut incoming);

                            for rel in outgoing {
                                if rel.rel_type == *rel_type {
                                    if let Some(entity) = self.entity_cartridge.read().unwrap()
                                        .get_by_id(&rel.to_entity)?
                                    {
                                        results.push(entity.clone());
                                    }
                                }
                            }
                        },
                    }
                },
                _ => {},
            }
        }

        // Rank results
        let ranker = ResultRanker {
            entity_cartridge: self.entity_cartridge.clone(),
            topic_cartridge: self.topic_cartridge.clone(),
        };

        let ranked = ranker.rank(results, plan)?;

        Ok(ranked.into_iter().map(|r| r.entity).collect())
    }
}
```

## Time-Travel Queries

### LSN-based Querying

```rust
impl QueryPlanner {
    /// Query database state at specific LSN
    pub async fn query_at_lsn(
        &self,
        nl_query: &str,
        lsn: Lsn,
    ) -> Result<QueryPlan> {
        // 1. Parse query normally
        let mut plan = self.plan(nl_query).await?;

        // 2. Add time-travel filter
        plan.operations.insert(0, QueryOperation::Filter {
            field: "commit_id".to_string(),
            operator: FilterOperator::LessThan,
            value: serde_json::json!(lsn.0),
        });

        // 3. Update intent to time-travel
        plan.intent = QueryIntent::TimeTravel { lsn };

        Ok(plan)
    }

    /// Explain what changed since specific LSN
    pub async fn explain_changes(
        &self,
        from_lsn: Lsn,
        to_lsn: Lsn,
    ) -> Result<ChangeExplanation> {
        let entity_cartridge = self.entity_cartridge.read().unwrap();

        // Get entities modified in range
        let mut entities = Vec::new();
        for txn_id in from_lsn.0..=to_lsn.0 {
            if let Some(txn_entities) = entity_cartridge.get_by_commit(txn_id) {
                entities.extend(txn_entities.iter().cloned());
            }
        }

        Ok(ChangeExplanation {
            from_lsn,
            to_lsn,
            modified_entities: entities.len(),
            entities: entities.into_iter().take(100).collect(),  // Limit
        })
    }
}

pub struct ChangeExplanation {
    pub from_lsn: Lsn,
    pub to_lsn: Lsn,
    pub modified_entities: usize,
    pub entities: Vec<Entity>,
}
```

## Caching and Performance

### Query Plan Cache

```rust
impl QueryOptimizer {
    /// Cache query plan for reuse
    pub fn cache_plan(&self, query: &str, plan: &QueryPlan) {
        let mut cache = self.query_cache.write().unwrap();
        cache.insert(query.to_string(), CachedPlan {
            plan: plan.clone(),
            timestamp: SystemTime::now(),
            hit_count: 0,
        });
    }

    /// Get cached plan if available
    pub fn get_cached(&self, query: &str) -> Option<QueryPlan> {
        let mut cache = self.query_cache.write().unwrap();
        if let Some(cached) = cache.get_mut(query) {
            cached.hit_count += 1;
            return Some(cached.plan.clone());
        }
        None
    }

    /// Evict stale cache entries
    pub fn evict_stale(&self, max_age: Duration) {
        let mut cache = self.query_cache.write().unwrap();
        let now = SystemTime::now();

        cache.retain(|_, cached| {
            now.duration_since(cached.timestamp)
                .map(|age| age < max_age)
                .unwrap_or(false)
        });
    }
}
```
